# pmm-aidd-workshop

## ワーク1 用プロンプト

```
逆ポーランド記法の電卓を作る

# Linux / Mac / WSL → Shell Script
./calc.sh 1 2 +    → 3
./calc.sh 3 6 *    → 18

# Windows → PowerShell
.\calc.ps1 1 2 +   → 3
.\calc.ps1 3 6 *   → 18
```


## ワーク2 用プロンプト

### Step1

```
sales-kpi.csv を読み込んで、売上の推移と地域別の比較が
一目で分かるHTMLレポートを作ってください。
ブラウザで開くだけで見られる単一のHTMLファイルにしてください。
```

### Step2

```
CAC（広告費 ÷ 新規顧客数）と解約率（解約顧客数 ÷ 週初のアクティブ顧客数）も
グラフに追加してください。
それと、このデータで異常に見える箇所があれば指摘してください。
```

### 応用(余裕があれば)

```
- グラフは単一HTMLに埋め込み、外部CDNに依存しない形で出力する
- 数値は3桁区切り、金額は千円単位で表示する
- レポートの先頭に「気づいた点」を3行以内で書く
```
